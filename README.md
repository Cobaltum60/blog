## 技术栈

- **前端**: 原生 HTML / CSS / JS
- **部署**: GitHub Actions 自动构建并发布至 GitHub Pages
- **域名**: Cloudflare 托管 `blog.cosixzero.com`

## 评论系统架构声明

- **存储**：基于 **Giscus**，评论数据直接存放在本仓库的 **Discussions** 中，无额外后端数据库。
- **权限**：访客必须登录 GitHub 账号方可评论，有效防止恶意刷评和垃圾广告。
- **管理**：博主可直接在 GitHub 后台删除违规评论或锁定帖子。
