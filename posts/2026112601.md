## 测试 C++
```cpp

int main() {
    std::cout << "Test C++" << std::endl;
    return 0;
}
```

## 测试 C
```c
#include <stdio.h>
int main() {
    printf("Test C\n");
    return 0;
}
```

## 测试 JS
```javascript
const test = () => {
    console.log("Test JS");
};
test();
```
